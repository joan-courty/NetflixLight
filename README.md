# NetflixLight

Prototype de plateforme de streaming utilisant l'API TMDB.

## Technologies
- HTML
- CSS / Tailwind
- JavaScript
- Node.js
- Express

## Fonctionnalités
- Catalogue de films
- Recherche
- Favoris
- Lecteur vidéo

## Installation

1. Installer les dépendances
npm install

2. Lancer le serveur
node server.js

3. Ouvrir le frontend
index.html
